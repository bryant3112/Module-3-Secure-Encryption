Secure Hashing and Encryption
In this assignment, I created a simple Python program to learn how hashing and encryption work. I also practiced using digital signatures to protect messages and verify that they have not been changed.

SHA-256 Hashing
I used SHA-256 to create hashes for messages and files. I learned that hashing turns information into a unique-looking value that can help us check if something has been changed.

Caesar Cipher Encryption
I created a Caesar cipher using Python. This lets me encrypt and decrypt messages by shifting letters. For example, I changed HELLO into KHOOR and then decrypted it back to HELLO.

Digital Signatures
I used OpenSSL to create a private key and a public key. I used the private key to sign a message and the public key to verify it. I also changed the message to test what would happen, and the verification failed because the message was different.

What I Learned 
This assignment helped me understand how hashing, encryption, and digital signatures work. I learned how these tools can helped protect information and check if files or messages have been modified.
